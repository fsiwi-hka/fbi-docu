# Beszel

## Domains

- beszel.iwi-hka.de

## Allgemeine Informationen

Beszel ist eine schlanke Plattform zur Serverüberwachung. Sie bietet Docker-Statistiken, historische Daten und Alarmfunktionen.

## Docker Compose und Speicherort

Docker Compose befindet sich unter `/opt/beszel`.

## Zugriff

Read Zugriff ist über den user Account `read@iwi-hka.de` erhältlich.
