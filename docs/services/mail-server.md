# Mailserver

## Domain

- `mail.iwi-hka.de`

## Komponenten

- **Postfix** und **Dovecot** bilden das Mail-Backend.
- **Roundcube** ist das Webmail-Frontend.

## Betrieb

Der Mailserver läuft auf einem separaten Server bei Hetzner. Postfix und
Dovecot wurden über `apt` installiert. Roundcube wurde manuell aus einem
Tarball installiert.

## Zugriff

Der Zugang zum Server und zu den Postfächern ist Mitgliedern des FBI und der
Fachschaft vorbehalten.
